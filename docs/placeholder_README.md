# NAM Documentation Folder

This folder contains the official documentation for the NAM Engine:

- NAM Whitepaper
- Developer Guide
- Overview
- Master Documentation

All versioned documentation bundles will be located in `/docs/versions/`.

This folder provides a centralized location for reference materials, PDFs, and supporting documents for developers, researchers, and collaborators working with the Noctilucan Aurogenesis Model (NAM).
